📋 Ma fiche mémo

Nombre relatifUn signe (+ ou −) et une valeur absolue.
Exemple : −4 → signe −, valeur absolue 4.
Valeur absolueLa distance jusqu’à 0. Elle n’a jamais de signe −.
Négatif / positifNégatif : signe −, à gauche de 0.
Positif : signe + (souvent pas écrit), à droite de 0.
0 : pas de signe, il est les deux.
AbscisseLe nombre qui repère un point sur une droite graduée.
On écrit : A(4) ; B(−5).
OpposéJe change seulement le signe : 4,5 ↔ −4,5.
Les deux points sont symétriques par rapport à O.
ComparerLe plus grand est le plus à droite.
• Un négatif est toujours plus petit qu’un positif.
• Deux négatifs : le plus grand a la plus petite valeur absolue (−2 > −5).
🐊 La bouche ouverte mange le plus grand : 3 < 7.
Coordonnées(abscisse ; ordonnée)
1) ← → sur l’axe horizontal 2) ↑ ↓ sur l’axe vertical.

👨‍👩‍👦 Pour l’adulte qui accompagne
  • Préférer 10 minutes par jour plutôt qu’une longue séance la veille.
  • Utiliser le bouton 🔊 : il lit les consignes à voix haute.
  • Il n’y a pas de chronomètre : laisser le temps de poser le doigt sur la droite graduée.
  • Les couleurs sont toujours les mêmes : bleu = négatif, rouge = positif, comme dans le cahier.
  • Après une erreur, faire relire l’explication à voix haute avant de passer à la suite.
